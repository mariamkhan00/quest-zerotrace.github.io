Undergraduate Program

Bachelor of Science in Cyber Security

BS Cyber Security

The Bachelor of Science in Cyber Security is a 4-year degree program designed to prepare students for the growing cybersecurity industry. The program equips students with the knowledge and skills to protect computer systems, networks, and data from cyber threats.

Program Details:
Duration: 4 Years (8 Semesters) Credit Hours: 135 Degree: BS Cyber Security
Eligibility Criteria:
  • FSc Pre-Engineering with minimum 60% marks.
  • Must pass the university entry test / interview.
Career Opportunities:

Graduates can work as Security Analysts, Penetration Testers, Digital Forensics Experts, SOC Analysts, and Network Security Engineers in public and private sectors.

# 🛡️ QUEST Cyber Security Department Website

Official web portal for the **Department of Cyber Security** at Quaid-e-Awam University of Engineering, Science & Technology (QUEST), Nawabshah.

## 🌟 Features
* **Dynamic Timetables:** Live daily class schedules for Morning & Evening shifts via Google Sheets.
* **SmartDay (PWA):** A mobile-friendly live daily timetable card for students.
* **AI Chatbot:** Integrated AI assistant for student queries.
* **Dark/Light Mode:** Fully responsive theme across all pages.
* **Faculty Directory:** Detailed profiles of all teaching staff.
* **News & Announcements:** Latest updates from the department.

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap 5)
* **Backend:** Google Apps Script
* **Database:** Google Sheets
* **Hosting:** GitHub Pages
